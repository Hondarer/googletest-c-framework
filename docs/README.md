# googletest-c-framework

Google Test を基盤とし、C/C++ 言語向けの単体テスト作成やモック化、テスト実行を支援するテスト フレームワークです。

C 関数のモック化技法、フェーズ別のテスト運用、カバレッジ計測やクロスプラットフォーム環境でのプロセス制御機能を提供します。
